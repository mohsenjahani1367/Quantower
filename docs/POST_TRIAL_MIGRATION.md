# Post-trial migration

Independent Core, CLI, JSONL recording/replay and public external provider do not use Quantower licensing. Keep recordings, source mappings and settings outside installation directories and preserve provenance.

The current Quantower replay indicator/native recorder may still require features licensed by Quantower. Verify actual restrictions after trial expiry; do not claim the present implementation bypasses a connection/indicator limit.

A single custom unified connector/external service is roadmap work, not delivered. Public external capture and offline reports are the current independent fallback. Licensing, native multi-connect and API access must be established before a custom connector architecture is finalized.
